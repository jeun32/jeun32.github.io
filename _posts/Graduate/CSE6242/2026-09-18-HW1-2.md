## <span style="color:#FEB99C;">1. Q3: D3.js로 가장 많이 밀수된 동물 TOP 5 시각화하기</span>

숫자로 가득 찬 엑셀 표는 한눈에 상황을 파악하기 어렵습니다. 그래서 웹 데이터 시각화 표준 도구인 **D3.js (v5)**를 사용해 2015년부터 2023년까지 가장 많이 밀수된 동물 종(Species) 상위 5개를 가로 막대그래프(Horizontal Bar Chart)로 표현했습니다.

### ① 자(Scale) 만들기: 데이터 숫자를 화면 픽셀로 변환
그래프를 그릴 때 가장 중요한 개념은 **스케일(Scale)**입니다. 밀수 건수가 3,000건이라고 해서 화면에 3,000픽셀짜리 막대를 그리면 모니터 밖으로 삐져나가 버립니다.

- **X축 (선형 스케일, `scaleLinear`)**: 밀수 건수(0 ~ 3,000건)를 화면 가로 폭(0 ~ 690픽셀)에 맞게 비율로 축소
- **Y축 (밴드 스케일, `scaleBand`)**: 5마리의 동물 이름을 위에서 아래로 일정한 두께의 막대 영역으로 균등 분할

```javascript
// X축: 데이터의 최댓값(3000)을 화면 폭에 매핑
var maxCount = d3.max(top5Data, function (d) { return d.count; });
var x = d3.scaleLinear()
    .domain([0, maxCount])
    .range([0, width]);

// Y축: 동물 이름들을 세로 층(Band)으로 배치
var y = d3.scaleBand()
    .domain(top5Data.map(function (d) { return d.species; }))
    .range([0, height])
    .padding(0.2);
```

### ② 디버깅 경험: `.nice()`의 함정
로컬에서 차트를 잘 띄운 뒤 채점기에 올렸는데, X축 테스트에서 점수가 깎이는 일이 있었습니다.
원인은 도메인 끝에 붙였던 **`.nice()`** 함수 때문이었습니다.

D3의 `.nice()`는 사람이 보기 편하게 축의 끝자리를 넉넉하게 반올림해 주는 기능입니다. 데이터 최댓값이 3,000인데 D3가 알아서 상한선을 `3500`으로 늘려버린 것이죠. 그 바람에 눈금(Tick) 개수가 7개가 아닌 8개가 생성되고, 막대 길이 비율까지 어긋났습니다.

`.nice()`를 걷어내고 데이터 최댓값(`maxCount = 3000`)을 그대로 고정하자, 눈금이 500 간격으로 정확히 7개(`0, 500, 1000, 1500, 2000, 2500, 3000`) 생성되면서 테스트를 모두 통과할 수 있었습니다.

## <span style="color:#FEB99C;">2. Q4: 엉망인 텍스트 데이터 청소하기 (OpenRefine)</span>

실제 수사 기록의 사건 요약문(`Subject`)은 전 세계 세관원들이 제각각 작성했기 때문에 형식이 매우 불규칙합니다.

> 예: *"77kg of sandalwood at the Chhatrapati Shivaji Maharaj International Airport, one Sudanese national"*  
> 예: *"reptiles seized from 2 suitcases at Mohammed V Airport"*

여기서 공항 이름만 정확하게 떼어내기 위해 데이터 정제 전용 도구인 **OpenRefine**과 정규표현식(GREL)을 활용했습니다.

### ① 전치사와 괄호를 기준으로 공항 이름 분리
단순히 "대문자로 시작하는 단어"만 찾으면 문장 앞의 `77kg`, `Reptiles seized at` 같은 사건 내용까지 공항 이름으로 묶여버리는 문제가 있었습니다.

문장을 분석해 보니 공항 이름 바로 앞에는 항상 **전치사(`at`, `in`, `from`, `seized`)나 쉼표(`,`), 또는 여는 괄호(`(`)**가 붙는다는 패턴을 발견했습니다.

```grel
value.match(/.*?(?:(?:at|in|from|seized)\s+(?:the\s+)?|,|\()(?:\s+)?([A-ZÀ-ÿ][A-Za-zÀ-ÿ0-9\s\.\-'\’\(\)]*?\bAirport)\b.*/)[0]
```

- 스페인어 공항 이름에 들어간 악센트 문자(`Potosí`의 `í` 등)를 놓치지 않도록 문자 범위를 `[A-ZÀ-ÿ]`로 확장
- 아포스트로피도 곧은 따옴표(`'`)뿐만 아니라 둥근 따옴표(`’`)까지 인식되도록 보완

### ② 오타와 명칭 차이 통합 (Clustering & Merge)
같은 공항인데도 어떤 행에는 `Bangkok International Suvarnabhumi Airport`, 다른 행에는 `Bangkok Suvarnabhumi Airport`로 적혀 있었습니다.

OpenRefine의 **Clustering(군집화)** 기능을 사용해 철자와 발음 알고리즘(`fingerprint`, `metaphone3` 등)으로 비슷한 이름들을 한 묶음으로 찾은 뒤, 하나의 표준 공항 이름으로 통합(Merge)하여 데이터의 중복과 왜곡을 제거했습니다.

## <span style="color:#FEB99C;">3. Q5: 웹 애플리케이션으로 데이터 서빙하기 (Flask)</span>

마지막 Q5에서는 사용자가 웹 화면에서 동물 분류(포유류, 조류, 파충류 등)를 선택하면, 실시간으로 해당 분류의 상위 10개 밀수 사건을 표로 보여주는 **Flask 백엔드 로직**을 작성했습니다.

`wrangling_scripts/Q5.py`에서 구현한 3단계 핵심 흐름은 다음과 같습니다:

```python
# 1. 드롭다운용 고유 동물 분류 목록 추출 및 알파벳 순 정렬
dropdown_options = sorted(list(set(row[1] for row in table)))

# 2. 사용자가 선택한 분류(filter_class)로 데이터 필터링
if filter_class:
    table = [row for row in table if row[1] == filter_class]

# 3. 밀수 적발 횟수(count) 기준 내림차순 정렬 후 상위 10개 추출
table.sort(key=lambda x: x[2], reverse=True)
table = table[:10]
```

1. **드롭다운 메뉴 구성**: 데이터 전체를 훑어 동물 분류(`row[1]`)를 중복 없이 추려내고(`set`), 알파벳 순(`sorted`)으로 정렬하여 웹 메뉴판 생성
2. **조건부 필터링**: 사용자가 고른 분류가 있다면 그에 해당하는 행만 남기고, 선택이 없다면 전체 데이터를 유지
3. **정렬 및 자르기**: 정수형으로 변환된 밀수 건수(`row[2]`)를 기준으로 내림차순 정렬한 뒤, 상위 10개 행(`[:10]`)만 잘라서 HTML 템플릿에 전달

Flask 로컬 서버를 띄운 뒤 브라우저에서 드롭다운 값을 바꿀 때마다 표의 데이터가 즉시 전환되는 것을 확인할 수 있었습니다.
